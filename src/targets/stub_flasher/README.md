# Flasher stub binaries

Included here are the flasher stub binaries from the [esptool](https://github.com/espressif/esptool) project, set 2 (`esptool/targets/stub_flasher/2`). Filenames match esptool (`esp32.json`, `esp32p4-rev1.json`, and so on).

The binaries were copied from [esp-flasher-stub v1.4.1](https://github.com/espressif/esp-flasher-stub/releases/tag/v1.4.1) (the [`esp-flasher-stub@1.4.1`](https://www.npmjs.com/package/esp-flasher-stub/v/1.4.1) npm package; byte-identical to esptool `master` at the time of the update), where the sources can be obtained.
